What these computation results mean

Computation, startup and memory are different measurements

Native Image compiles ahead of time and often reduces startup work and runtime memory. The JVM can optimize hot code with its JIT compiler and can match or exceed native computation speed. Neither must win this workload. First samples are after startup; a few sequential calls do not establish steady state, sustained throughput, p99 or an SLO. Browser HTTP includes network, queueing and serialization; server duration measures only the algorithm. RSS includes more than heap; artifact bytes are not image bytes.

Measurement definitions

Server computation: duration_ns around the algorithm only. Browser HTTP: performance.now() through response body receipt; includes network, queuing and serialization. Heap and non-heap use bytes ÷ 1,048,576 (MiB); neither is RSS or container memory. Unknown or negative values are unavailable. Ratios require matching input, results and timing boundary, with positive values. Resource differences are displayed separately.
