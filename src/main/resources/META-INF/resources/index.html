AOT · NATIVE IMAGE

Prepare ahead of time.

Startup work and runtime memory can decrease because compilation happens during the build. That moves cost into build time.

JIT · JVM

Optimize as it runs.

The JIT can optimize hot code. Repeated computation can match or exceed native; neither runtime must win this workload.

Measurement definitions

        

          Server computation: duration_ns around the algorithm only. Browser
          HTTP: performance.now() through response body receipt; includes
          network, queuing and serialization. Heap and non-heap use bytes ÷
          1,048,576 (MiB); neither is RSS or container memory. Unknown or
          negative values are unavailable. Ratios require matching input,
          results and timing boundary, with positive values. Resource
          differences are displayed separately.
